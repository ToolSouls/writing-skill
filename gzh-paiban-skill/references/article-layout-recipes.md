# 文章类型布局配方

本文件定义宏观阅读结构；具体组件从所选主题库和 `common-components.md` 中取。

## 1. 教程 / 操作指南

### A. 结论先行

`封面 → 结果承诺 → 前置条件 → 编号步骤 → 关键截图 → 易错点 → 检查清单 → 结尾`

### B. 问题修复

`封面 → 错误现象 → 原因拆解 → 修复步骤 → 验证方式 → 预防建议 → CTA`

### C. 从零完成

`封面 → 成品预览 → 工具准备 → 分阶段步骤 → 中途检查点 → 最终效果 → 延伸阅读`

## 2. 观点 / 深度分析

### A. 反常识

`短封面 → 常见认知 → 转折问题 → 三个论据 → 反例 → 新结论 → 开放问题`

### B. 现象拆解

`场景开场 → 表层现象 → 深层机制 → 影响对象 → 正反案例 → 行动建议`

### C. 结论先行

`核心结论 → 证据一 → 证据二 → 反方观点 → 回应 → 边界条件 → 总结`

## 3. 清单 / 工具盘点

### A. 排名型

`封面 → 选择标准 → 条目排名 → 对比表 → 场景推荐 → 避坑 → 总结`

### B. 场景型

`封面 → 三个使用场景 → 每个场景对应工具 → 组合方案 → 成本提示 → CTA`

### C. 极简目录

`封面 → 三行导航 → 条目卡连续排布 → 快速选择表 → 最终推荐`

## 4. 产品测评 / 对比

### A. 实测型

`封面 → 测试问题 → 测试方法 → 实测结果 → 优缺点 → 适合谁 → 结论`

### B. 对照型

`封面 → 指标总览 → 维度对照 → 差异解释 → 使用场景 → 推荐矩阵`

### C. 单点深挖

`封面 → 最意外发现 → 功能拆解 → 与替代方案比较 → 限制条件 → 结论`

## 5. 案例复盘

### A. 结果倒叙

`结果数据 → 初始困境 → 关键决策 → 执行过程 → 失败节点 → 最终复盘`

### B. 时间线

`背景 → 时间线节点 → 转折点 → 结果 → 可复制动作 → 不可复制条件`

### C. 问题递进

`问题一 → 处理 → 新问题 → 处理 → 核心教训 → 行动清单`

## 6. 访谈 / 人物故事

### A. 金句开场

`人物金句 → 人物身份 → 关键经历 → 低谷 → 转变 → 近况 → 编辑手记`

### B. 场景开场

`一个具体动作 → 场景描写 → 人物背景 → 三次选择 → 结果 → 作者观察`

### C. 问答推进

`人物简介 → 核心问题一 → 回答 → 核心问题二 → 回答 → 核心问题三 → 总结`

## 7. 数据报告 / 市场分析

### A. 结论先行

`报告封面 → 执行摘要 → 核心指标 → 图表 → 研究发现 → 风险 → 行动建议`

### B. 变化追踪

`报告封面 → 上期结论 → 本期变化 → 时间线 → 原因分析 → 下期判断`

### C. 多维对照

`研究问题 → 方法口径 → 维度对照 → 异常值 → 解释 → 结论边界`

## 8. 情感 / 生活随笔

### A. 单场景深写

`一个动作或对白 → 当时感受 → 回忆补充 → 认知转折 → 当下的自己 → 温柔收尾`

### B. 片段组接

`三个生活片段 → 共同情绪 → 反思 → 新的选择 → 留白式结尾`

### C. 对读者说话

`直接称呼读者 → 描述困境 → 提供理解 → 给出小行动 → 安抚式收尾`

## 组件选择约束

- 主题库给出视觉组件，本文类型配方给出宏观顺序。
- 每个配方只选一个主路线；不要把 A/B/C 三种骨架混在同一篇。
- 主题库的“文章类型配方”优先级高于默认骨架；本文件的宏观顺序优先于两者。
- 若内容不足，删除对应区块，不用占位文案凑结构。
