# 文章布局变化引擎

排版不是“选一套主题后所有文章都套同一骨架”。每次排版同时确定三层：

1. **视觉主题**：决定色彩、字体、圆角、装饰语言。
2. **文章类型配方**：决定开场、论证顺序、内容单元和结尾方式。
3. **单篇变化签名**：用文章标题生成稳定但分散的版式选项，让同一主题、同一类型的文章也不完全相同。

## 单篇签名

运行：

```bash
python scripts/layout_variant.py "<文章标题>" "<文章类型>" "<主题ID>"
```

脚本输出：

```json
{
  "layout_id": "analysis-c",
  "opening": "question",
  "toc": "none",
  "heading_rhythm": "alternate-long-short",
  "emphasis": "one-anchor-per-section",
  "media_cadence": "after-second-section",
  "ending": "forward-looking",
  "density": "medium",
  "seed": "..."
}
```

同一标题重复生成时结果稳定；标题不同则布局组合变化。

## 变化边界

允许变化：

- 开场用结论、问题、场景或数据切入。
- 目录用完整目录、三行导航、无目录或文末回顾。
- 章节节奏用摘要先行、案例先行、问题递进或步骤推进。
- 图片与卡片交替频率。
- 结尾用总结、行动清单、开放问题或互动。

禁止变化：

- 一篇文章混用两套视觉主题。
- 同一篇中出现多种主色。
- 为了“不同”而破坏阅读顺序。
- 使用平台不兼容的布局能力。
- 每段都套卡片、每节都用大标题或每段都加粗。

## 美感规则

1. 全文视觉锚点不超过 5 处；正文关键词每段 1–3 个。
2. 相邻两个区块不能使用同一种重卡片样式。
3. 连续正文不超过 4 段，之后插入小标题、引用、图片、数据或留白变化。
4. 同一篇最多使用 3 类点缀组件。
5. 文章少于 1200 字时，省略完整目录；章节少于 3 个时不生成目录。
6. 没有图片和数据时，用引言、短段、标签小标题和留白建立节奏，不伪造图表。
7. 结尾只保留一个主 CTA；作者卡与互动 CTA 不重复堆叠。

## 输出前检查

- 是否使用了文章类型对应的布局配方，而不是主题默认骨架？
- 是否至少有两个结构选择由单篇签名决定？
- 视觉重点是否少于或等于 5 个？
- 是否删除了空图片、空目录和占位组件？
- 是否通过 `scripts/validate_gzh_html.py`？
